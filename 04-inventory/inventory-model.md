# Inventory Model

## Inventory KPIs
- Total units
- Available units
- Pending units
- Reserved units
- Sold units
- Inventory value
- Available inventory value
- Sold value
- Sales velocity
- Days in inventory
- Unit mix
- Inventory by project/phase/type

## Unit Availability Rule

A unit is available only when:
- unit status = Available
- no active non-expired reservation exists
- no active contract exists
- no management hold exists

## Inventory Aging

Suggested bands:
- 0–30 days
- 31–90 days
- 91–180 days
- 181–365 days
- >365 days
