# Sales Pipeline

## Suggested Stages
1. New Lead
2. Contacted
3. Qualified
4. Meeting / Presentation
5. Unit Proposed
6. Negotiation
7. Reservation
8. Contracted
9. Lost

## Core Metrics

| KPI | Formula |
|---|---|
| Lead-to-Opportunity % | Qualified opportunities / leads |
| Opportunity-to-Reservation % | Reservations / qualified opportunities |
| Reservation-to-Contract % | Contracts / reservations |
| Lead-to-Sale % | Contracts / leads |
| Average Sales Cycle | Contract date - lead date |
| Cancellation % | Cancelled contracts / signed contracts |

## Required Dimensions
- Project
- Sales team
- Salesperson
- Lead source
- Channel
- Broker
- Campaign
- Customer segment
