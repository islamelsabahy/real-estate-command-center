# Collections Model

## Core KPIs

| KPI | Definition |
|---|---|
| Contracted Value | Net active contract value |
| Due to Date | Installments due on/before reporting date |
| Collected to Date | Posted receipts on/before reporting date |
| Collection % | Collected / Due |
| Outstanding | Contract value - Collected |
| Overdue | Past-due unpaid installment amount |
| Upcoming 30 Days | Installments due in next 30 days |
| Returned Cheques | Value/count of returned instruments |

## Aging Bands
- Current / Not Due
- 1–30 overdue
- 31–60 overdue
- 61–90 overdue
- 91–180 overdue
- >180 overdue
