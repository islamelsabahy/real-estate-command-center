# Cheque Controls

Recommended cheque statuses:
- Received
- Deposited
- Cleared
- Returned
- Replaced
- Cancelled

Controls:
- [ ] Cheque number captured
- [ ] Bank captured
- [ ] Due date captured
- [ ] Customer/contract linkage
- [ ] Instrument amount reconciles to allocation
- [ ] Return reason recorded
- [ ] Replacement cheque linked to original
- [ ] Returned cheque reflected in overdue exposure
